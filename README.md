# INDUSTRIXXX

Премиальный многостраничный B2B-магазин промышленных вычислительных систем.

## Запуск в Windows CMD

```cmd
cd путь\к\папке\INDUSTRIXXX
npm install
npm run dev
```

Откройте адрес Vite, который появится в терминале (обычно `http://localhost:5173`).

## Сборка

```cmd
npm run build
```

## Стек

- React + TypeScript
- Vite
- React Router
- Lucide React
- Структурированная CSS-архитектура

## Реализовано

- Главная, каталог, страницы категорий и отдельные карточки 24 товаров
- Поиск по названию, артикулу и производителю
- Фильтры по категории, производителю, процессору, цене и наличию
- Сортировка по популярности, цене и новизне
- Корзина с количеством и пересчётом суммы
- Избранное
- Сохранение корзины и избранного в localStorage
- Страницы «О компании», «Доставка и оплата», «Контакты» и «Запрос КП»
- Адаптивная вёрстка и мобильная навигация

## Важно

Каталог, цены, артикулы, наличие и характеристики — демонстрационные данные для учебного проекта, а не реальные коммерческие предложения. Формы работают как интерфейсные демо-сценарии и не отправляют заявки на сервер. Фотографии загружаются с Unsplash по сети; при необходимости их можно заменить локальными файлами в `public/images` и обновить пути в `src/data/products.ts`.
